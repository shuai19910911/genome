# genome docs

本目录只保留适合在 GitHub 阅读的关键进展文档。

- `current-download-status.md`: 当前下载、补注释和验证进展。
- `2026-06-07-data-availability-audit.md`: 当前数据可用性审计结论。
- `2026-06-07-validation-experiment-plan.md`: 外部注释验证策略和结果概要。
- `2026-06-07-next-annotation-recovery-plan.md`: 后续注释补全计划。

中间候选表、索引表、逐条验证报告和运行日志只保留在本地 `local_reports/`、`validation_reports/` 或对应缓存目录，不上传 GitHub。
